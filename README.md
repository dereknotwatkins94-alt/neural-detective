# Neural Detective · 1.0.0

Русскоязычная детективная игра на Python / PySide6: четыре подозреваемых,
шесть улик, допросы, проверка показаний и три концовки. Реализованы все пять этапов.
Без ключа и без интернета можно полностью пройти дело в **AI DEMO MODE**.

## Быстрый запуск

Нужен Python 3.11+. В текущем окружении проект проверен на Python 3.14.

```sh
cd neural_detective
python -m venv .venv
```

Активация Windows: `.venv\Scripts\Activate.ps1`.
Активация macOS/Linux: `source .venv/bin/activate`.

```sh
python -m pip install -r requirements.txt
python main.py
```

Зависимости в текущей рабочей папке уже установлены. На macOS можно сразу запустить
`.venv/bin/python main.py`. Для защиты модели от несовместимости sklearn версия
проверяется при загрузке; при необходимости она переобучается локально.

## Как играть

1. Начните новое расследование, прочитайте обзор.
2. В «Уликах» запросите медицинское заключение, затем изучите его.
3. Откройте досье подозреваемого и перейдите к допросу.
4. Выбирайте готовые вопросы или вводите свои на русском. Можно менять тон.
5. Новые сведения открывают основания для запроса других материалов.
6. Предъявляйте изученные улики конкретным персонажам. Простого получения
   документа недостаточно для подтверждения противоречия.
7. Добавляйте ответы в журнал ссылкой «В журнал», пишите заметки.
8. В лаборатории ML сравнивайте два текста из показаний и улик либо свои тексты.
9. В «Обвинении» выберите человека, приложите изученные доказательства и объясните
   версию. После подтверждения откроются развязка, хронология и оценка.

Подсказка следующего шага находится в обзоре. Агрессивный допрос не создаёт тупиков.
Ложь не обязательно означает виновность. Для полной концовки нужны ключевые
доказательства и подтверждение противоречия алиби; все побочные секреты не обязательны.
Свободный вопрос, не покрытый известными фактами, получает просьбу уточнить его.
Готовые вопросы всегда остаются доступным маршрутом прохождения.

## ИИ и настройки

В «Настройках» можно ввести ключ, выбрать модель, проверить подключение и отключить
деморежим. Кнопка «Применить» применяет значения; проверка соединения сама по себе
не меняет выбранный режим. Масштаб 90–125% применяется после перезапуска.

Ключ также читается из переменной `GEMINI_API_KEY`, `.env` в корне проекта или
`user_data/.env`. Шаблон — `.env.example`. Модель задаётся через `GEMINI_MODEL`
или настройки; по умолчанию `gemini-3.1-flash-lite`. Доступность модели, региона,
бесплатных квот и лимитов зависит от аккаунта Google. При ошибке или исчерпании
лимита игра автоматически использует локальный ответ и сообщает об этом.
Ни ключ, ни сетевые исключения с содержимым запросов не записываются в SQLite/логи.
Сохранение ключа в локальный `.env` требует отдельной галочки. Сам файл не шифруется.

Используется официальный [Google Gen AI SDK](https://googleapis.github.io/python-genai/).
Список идентификаторов — в [документации моделей Gemini](https://ai.google.dev/gemini-api/docs/models).

**Защита сценария:** Gemini определяет тему свободного вопроса, выбирает порядок
разрешённых фактических фрагментов и эмоциональную подачу. Прямой произвольный
текст LLM не выводится: `FactValidator` проверяет структуру и полный набор индексов,
затем ответ собирается из реплик, разрешённых игровым движком. Это осознанно
ограниченный разговор: модель не может выдумать улику, изменить преступника или
открыть закрытый секрет. Промпт получает только публичный профиль, допустимые
ответы текущего персонажа и историю его допроса, без полной закрытой хронологии.
API-провайдер заменяем через протокол `AIProvider`. Сеть выполняется в QThread,
таймаут одного запроса — 20 секунд, проверка ответа повторяется не более одного раза.
На время операции повторная отправка и действия, меняющие снимок дела, отключены;
интерфейс продолжает обрабатывать события и показывает индикатор ожидания.
Источник каждого ответа указан в чате. Статус CONNECTED появляется только после
реального успешного запроса; наличие ключа само по себе его не устанавливает.

## ML

В `ml/dataset.csv` — 240 синтетических размеченных пар: 180 для обучения, 60 для
отложенной оценки. Целые группы речевых шаблонов разделены между наборами,
подстановки одного шаблона не попадают одновременно в train и test.
Есть отрицания, времена, места, согласующиеся и не связанные утверждения.

Модель: символьный TF-IDF (3–5-граммы) + симметричная разность и произведение
векторов двух фраз + числовые признаки пары + Logistic Regression.
Это **обучаемая локальная модель**, не вызов Gemini и не набор готовых меток.
Показатель уверенности — вероятность классификатора, не вероятность виновности.

На включённом отложенном наборе: accuracy 0,80; macro precision 0,82;
macro recall 0,80; macro F1 0,80. Полный отчёт, матрица ошибок, версии и хеш
датасета — `ml/models/metrics.json`. Набор небольшой и шаблонный; эти числа
не являются оценкой качества на произвольной русской речи. Верные перефразирования
модель иногда считает противоречиями. Подтверждённые противоречия игры вычисляются
отдельными структурированными правилами и не зависят от ML.

Обученная модель включена. Можно редактировать датасет и переобучать кнопкой
в журнале либо из терминала:

```sh
python -m ml.train_model
```

Генератор исходного учебного набора: `python -m ml.build_dataset` (перезаписывает CSV).
Обучение из UI сохраняет пользовательскую модель в `user_data/ml`, не меняя
поставляемую модель. При ошибке/отсутствии модели можно нажать «Переобучить».
Файлы joblib загружаются только из локальных каталогов приложения.

## Сохранения

Автосохранение SQLite выполняется после действий и редактирования заметок с
короткой задержкой; есть кнопка «Сохранить» и сохранение при выходе. После перезапуска
«Продолжить» восстанавливает выбранный раздел и персонажа, улики, всю историю,
доверие/стресс, секреты, предъявления, журнал, заметки, гипотезы ML, черновик
обвинения и финальное решение. Новое расследование подтверждается перед заменой.

При запуске из исходников данные лежат в `user_data/`. В Windows-сборке —
`%LOCALAPPDATA%\NeuralDetective`. Путь можно изменить через `NEURAL_DETECTIVE_HOME`.
SQLite хранит один слот дела, версию формата и время записи. Транзакция атомарна.
Повреждённый файл автоматически не затирается; ошибка показывается пользователю.
Для переноса прогресса скопируйте `investigation.db` при закрытой игре.

## Структура

- `main.py`, `ui/` — окно, оформление, экраны и асинхронные действия.
- `core/` — движок, состояния, конфигурация и сохранения.
- `ai/` — Gemini, демопровайдер, промпт, агент и проверка фактов.
- `database/` — SQLite.
- `ml/` — признаки пары, CSV, обучение, модель и метрики.
- `data/case_001.json`, `characters.json` — публичные сведения.
- Остальные файлы `data/` и `docs/SCENARIO.md` — **спойлеры**, закрытый сценарий.
- `assets/` — локальные SVG и изображения; портреты пока заменены инициалами.
- `tests/` — ключевые проверки движка, UI, сохранений и защиты ИИ.

Фон взят из предоставленного пользователем концепта. Исходная папка
`Neural_Detective_UI_Concept` не менялась. Звуки не реализованы; отдельного
переключателя не добавлено. Система файлов локальная: разделение секретов
защищает игровой UI, но не мешает владельцу прочитать JSON самостоятельно.

## Сборка и передача

Windows-сборка выполняется **на Windows** с установленным Python:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```

Скрипт установит PyInstaller, переобучит модель под текущую версию sklearn
и создаст `dist\NeuralDetective\NeuralDetective.exe`. Передавать нужно всю
папку `dist\NeuralDetective`, не один exe. В сборку включаются JSON, изображения,
датасет и модель; ключи и сохранения не включаются. Windows-exe в текущей macOS-среде
не собирался. На macOS/Linux можно использовать тот же spec, установив PyInstaller,
но результат предназначается только для ОС сборки.

Архив исходников без ключей, личных сохранений и виртуального окружения:

```sh
python scripts/package_source.py
```

## Короткая проверка

```sh
python -m pytest -q
```

Есть проверка полного прохождения через UI, всех концовок, сериализации состояния,
восстановления окна, демодиалога, отказа провайдера и отклонения выдуманных фактов.
Qt-проверки выполняются offscreen. Живое подключение Gemini требует вашего ключа
и отдельно проверяется кнопкой в настройках. В текущей среде без ключа живой
запрос не выполнялся; интеграция проверена по SDK и через подменяемых провайдеров.
